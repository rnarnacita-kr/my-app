# 매출 대사 SQL

온라인 쇼핑몰 주문 · 출고 · 정산 데이터를 한국어로 묻고, AI가 쓴 DuckDB SQL을 브라우저 안에서 실행해 결과와 근거를 보여 주는 앱입니다. `data/` 는 수업용 가상 데이터입니다.

## 쓰기 전에

1. 이 앱은 데이터를 브라우저 안에서 읽는다. 올린 파일은 서버에 저장되지 않는다.
2. AI에는 질문 · 테이블 설명 · 집계 결과(최대 50행)만 간다. 원본 행은 가지 않는다.
3. AI가 쓴 SQL은 실행 전에 읽어 보고, 결과 숫자 하나는 직접 검산한다.
4. 올린 파일의 «읽은 행 수»와 «올라간 행 수»가 다르면(✕) 그 결과를 믿지 않는다.
5. 파일 이름이 같으면 나중에 올린 파일이 앞의 것을 대신한다.
6. 추출 파일은 추출한 날까지의 누적이라, 월말에 주문한 건의 출고와 정산은 다음 달 파일에서 채워진다.

## 내 PC에서 띄우기

1. `.env.example` 을 `.env` 로 복사하고 `GEMINI_API_KEY` 를 채운다 (`GEMINI_MODEL` 은 비우면 `gemini-3.5-flash-lite`).
2. `python tools/serve.py` → http://127.0.0.1:8780

외부 패키지 설치는 필요 없습니다(Python 표준 라이브러리 + CDN에 버전을 고정한 DuckDB-WASM · SheetJS).

## Vercel에 배포하기

- 이 폴더를 그대로 배포합니다. 루트의 파일은 정적 파일로, `api/sql.py` · `api/why.py` 는 Python 함수로 올라갑니다(`_` 로 시작하는 파일은 함수가 아니라 공통 모듈).
- Vercel 프로젝트의 Environment Variables 에 `GEMINI_API_KEY`(필수), `GEMINI_MODEL`(선택)을 넣습니다.
- `.vercelignore` 로 `tools/` · `.env` · `다음달/` 은 배포에서 빠집니다. `data/` 는 가상 데이터라 포함합니다.
