# 데이터 사전 — 재무·회계 (온라인 쇼핑몰 판매 회사 · 주문 · 출고 · 정산)

> 이 데이터는 수업용으로 만든 **합성 데이터**입니다. 실제 회사 · 실제 사람과 관계가 없습니다.

## 어떤 회사의 데이터인가

온라인 쇼핑몰 다섯 곳(자사몰 · 오픈마켓A · 오픈마켓B · 소셜커머스 · 종합몰)에서 생활용품 · 식품 · 뷰티 · 건강기능식품 · 주방 · 반려동물 상품을 파는 회사입니다. 재무팀은 쇼핑몰이 내려 주는 **주문 엑셀**을 창고의 **출고 엑셀**과 맞춰 보고 «실제로 출고된 수량»으로 매출을 확정한 뒤, 쇼핑몰이 입금한 **정산 내역**과 대조하고 세트 상품은 단품으로 환산해 원가와 마진을 계산합니다.

- 기간: **2024-07-01 ~ 2025-12-31** (18개월).
- `다음달/` 폴더에는 2026-01까지 늘어난 같은 이름의 파일 세 개(`mall_orders` · `shipments` · `mall_settlements`)가 있습니다.

## 테이블 한눈에

| 테이블 (파일) | 한 행 = | 행 수 | 키 |
|---|---|---:|---|
| `products` | 상품 1개 (단품 120개 + 세트 24개) | 144 | sku |
| `set_components` | 세트 1개의 구성 단품 1개 | 71 | set_sku + component_sku |
| `mall_orders` | 쇼핑몰 주문의 항목 1개(상품 1종) | 57,530 | order_no + line_no |
| `shipments` | 출고 1건 (주문 항목 하나에 대한 창고 출고) | 54,407 | ship_id (order_no + line_no로 주문과 연결) |
| `mall_settlements` | 쇼핑몰이 입금한 정산 1건 (출고 한 건에 대한 입금) | 53,570 | settle_id (order_no + line_no로 주문과 연결) |

관계: `mall_orders` 1 : 0~1 `shipments` (`order_no` + `line_no`). 출고가 없는 주문 항목이 있습니다 / `shipments` 1 : 0~1 `mall_settlements` (같은 키) / `mall_orders.sku` → `products.sku` / `set_components.set_sku` → `products.sku` (세트) · `component_sku` → `products.sku` (단품)

## 컬럼

### products

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| sku | 문자 | 상품 코드. 단품은 `S0001` 형태, 세트는 `SET01` 형태 |
| product_name | 문자 | 표준 상품명 |
| category | 문자 | 카테고리 (6개) |
| list_price | 정수 | 정가(원) |
| unit_cost | 정수 | 단품 원가(원). **세트는 결측값** — set_components로 환산 |
| is_set | 정수 | 1이면 세트 상품 |

### set_components

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| set_sku | 문자 | 세트 코드 |
| component_sku | 문자 | 구성 단품 코드 |
| qty | 정수 | 세트 하나에 들어가는 이 단품의 수량 |

### mall_orders

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| order_no | 문자 | 주문 번호 |
| line_no | 정수 | 주문 안의 항목 번호 |
| mall | 문자 | 쇼핑몰 이름 (5개) |
| order_date | 날짜 | 주문일 |
| mall_product_name | 문자 | 쇼핑몰이 쓰는 상품명. **쇼핑몰마다 표기가 달라 조인 키로 쓰지 않습니다** |
| sku | 문자 | 상품 코드 (조인 키) |
| qty | 정수 | 주문 수량 |
| unit_price | 정수 | 판매 단가(원) |
| sales_amount | 정수 | 판매 금액 = 단가 × 수량 |
| payment_amount | 정수 | 결제 금액 = 판매 금액 − 쿠폰 할인 |

### shipments

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| ship_id | 문자 | 출고 번호 |
| order_no | 문자 | 주문 번호 |
| line_no | 정수 | 주문 항목 번호 |
| sku | 문자 | 출고한 상품 코드 |
| ship_date | 날짜 | 출고일 |
| ship_qty | 정수 | 출고 수량. 주문 수량보다 적을 수 있음(부분 출고) |

### mall_settlements

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| settle_id | 문자 | 정산 번호 |
| order_no | 문자 | 주문 번호 |
| line_no | 정수 | 주문 항목 번호 |
| mall | 문자 | 입금한 쇼핑몰 |
| settle_date | 날짜 | 입금일 |
| deposit_amount | 정수 | 입금액(원) |

## 지표 정의 — 이 회사의 기준

| 지표 | 정의 |
|---|---|
| 주문 매출 | `mall_orders.sales_amount`의 합. 주문일 기준 |
| 출고 매출 | `shipments.ship_qty × mall_orders.unit_price`의 합. **출고일 기준**으로 월을 나눕니다. 회사의 확정 매출은 출고 매출입니다 |
| 미출고 수량 | 주문 수량 − 출고 수량 (출고 행이 없으면 출고 수량은 0) |
| 세트 환산 원가 | `set_components`의 구성 단품 `unit_cost × qty` 합 |
| 마진 | 판매 단가 − 원가 (세트는 환산 원가). 쇼핑몰 수수료는 포함하지 않습니다 |
| 입금률 | 입금액 ÷ 결제금액 중 출고된 분량. 쇼핑몰 수수료율만큼 100%보다 낮은 것이 정상입니다 |

## 회사 규칙 (숫자를 읽을 때 알아야 하는 것)

- 출고는 주문 다음 날부터 1~3일 걸립니다. 토 · 일에는 출고하지 않아 월요일로 넘어갑니다. 월말 주문은 다음 달에 출고됩니다.
- 12월 26일부터 말일까지는 연말 프로모션 기간이라 출고가 3~8일 걸립니다.
- 쇼핑몰 수수료율: 자사몰 3% · 오픈마켓A 11% · 오픈마켓B 12% · 소셜커머스 20% · 종합몰 13%. 정산은 출고일 8일 뒤(주말이면 월요일)에 입금됩니다.
- 주문 취소와 품절은 `shipments`에 행이 없는 것으로만 나타납니다. 취소 사유 컬럼은 없습니다.
